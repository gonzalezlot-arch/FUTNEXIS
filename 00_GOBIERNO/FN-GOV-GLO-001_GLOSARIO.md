# FN-GOV-GLO-001 — Glosario maestro

- Versión: 1.0
- Estado: BORRADOR
- Fecha: 2026-11-02

Glosario transversal; se amplía conforme evoluciona el producto.

## Producto y organización
| Término | Definición |
|---|---|
| FUTNEXIS | Plataforma SaaS para administración de torneos de fútbol. |
| SaaS | Software ofrecido como servicio. |
| Multitenant | Arquitectura con varias organizaciones y aislamiento lógico de datos. |
| Organización | Entidad cliente que administra torneos. |
| Propietario | Usuario con titularidad principal de una organización. |
| Membresía | Relación entre usuario y organización, con rol y estado. |
| Portal público | Sitio público sujeto a configuración y publicación. |

## Gestión deportiva
| Término | Definición |
|---|---|
| Torneo | Competición administrada por una organización. |
| Modalidad | Formato de fútbol 5, 6, 7, 9 u 11. |
| Jornada | Agrupación de partidos del calendario. |
| Acta | Registro oficial de hechos y resultado de un partido. |
| Resultado confirmado | Resultado validado por usuario autorizado. |
| Nombre deportivo | Nombre visible de un jugador en contexto deportivo. |
| Avance deportivo | Progresión de un equipo por las fases de un torneo. |

## UX/UI y tecnología

| PWA | Aplicación web progresiva. |
| Dashboard | Panel principal de indicadores y accesos. |

## Gobierno documental
| Término | Definición |
