# FUTNEXIS

**SPORTS TECHNOLOGY**  
*Cada torneo, bajo control.*

## Propósito

FUTNEXIS es una plataforma SaaS multiempresa para la gestión integral de torneos de fútbol, organizaciones, equipos, jugadores y competiciones.

Este repositorio es la **fuente maestra de documentación del producto**. Las decisiones aprobadas, especificaciones, cambios y versiones vigentes deben registrarse aquí para mantener continuidad entre conversaciones, herramientas y etapas de desarrollo.

## Estado del proyecto

- Etapa: definición funcional, UX/UI y preparación de arquitectura.
- Desarrollo: no iniciar módulos hasta aprobar sus especificaciones y criterios de aceptación.
- Modalidades previstas: fútbol 5, 6, 7, 9 y 11.
- Modelo: SaaS multiempresa/multitenant.
- Canales previstos: web adaptable y PWA.

## Estructura documental

- `00_GOBIERNO/`: metodología, decisiones, glosario e inventario documental.
- `01_PRODUCTO/`: visión, alcance y definición funcional.
- `02_MARCA/`: identidad y posicionamiento.
- `03_UX_UI/`: experiencia, navegación y diseño.
- `04_ARQUITECTURA/`: arquitectura tecnológica y datos.
- `05_MODULOS/`: especificaciones funcionales por módulo.
- `06_API_SEGURIDAD/`: contratos, integraciones, seguridad y privacidad.
- `07_DESARROLLO/`: guías e instrucciones de implementación.
- `08_CALIDAD/`: pruebas, incidencias y aceptación.
- `09_OPERACIONES/`: despliegue, respaldo y operación.
- `10_HISTORICO/`: material obsoleto y versiones históricas que deban conservarse.

## Reglas esenciales

1. Este repositorio es la referencia documental vigente; las conversaciones no sustituyen el registro.
2. Una decisión solo se considera persistida cuando está registrada en GitHub.
3. No sobrescribir ni eliminar decisiones históricas: corregir mediante nuevas versiones y trazabilidad.
4. Diferenciar siempre confirmado, propuesta, pendiente, supuesto y fuera de alcance.
5. No iniciar desarrollo de un módulo sin especificación y criterios de aceptación aprobados.
6. No almacenar secretos, credenciales, tokens ni datos personales reales.
